How to find your file

  1. Connect your Kobo to your computer via USB
  2. Open the Kobo drive in your file manager
  3. Navigate to the hidden .kobo folder
    • Windows: Enable "Show hidden items" in the View menu
    • Mac: Press Cmd+Shift+. to show hidden files
  4. Upload the KoboReader.sqlite file found there

Your file is processed locally on this server and deleted immediately after. Nothing is stored.
